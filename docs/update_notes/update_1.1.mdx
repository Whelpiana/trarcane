# TRARCANE UPDATE 1.1

An update bringing new items, skills, bug fixes, and wiki improvements.

## Fixed

* Fixed a crash caused by **Disintegration** and **Mega Disintegration**.

* Race Mixins
  * Added the race mixins to the wiki.

---

## Added

* **Automatic Race & Skill Config Registration**

  * Races and skills are now automatically added to the config.
  * **The existing config file must be deleted** for the new entries to generate.

* **Measure**

  * Added the **Measure** Extra Skill.

* **Gauntlet**

  * Added the new **Eclipse Gauntlet** item.

* **Eclipse Ingot**

  * Added a new crafting material: **Eclipse Ingot**.
  * Currently used to craft the Gauntlet but more **Eclipse Items** are planned for future updates.

* **Race Prestige Integration**

  * Added support for the Tensura: Arcane Races for the **SlimeThrone Extras Race Prestige** addon.
  * Completing each race's requirements awards **4 Soul Grade Points**.
  * Each race's requirements can be viewed in-game.

---

## Updated

* Updated the wiki with documentation for all new additions in Update 1.1.
