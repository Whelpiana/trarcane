# TRARCANE UPDATE 1.3

An update adding a new Extra Skill and configurable values for items and skills.

## Updated

* Updated the wiki with documentation for all new additions in Update 1.3.
* Updated all **Extra** and **Unique Skills icons** with remade icons.


## Added

* **Clairvoyance**

  * Added the **Clairvoyance** Extra Skill.

* **Configurable Item and Skill Settings**

  * Added config options for some item, Extra Skills and Unique Skill.


## Config Files

The config files are generated in the Minecraft config directory:

* `trarcane/items/items_config` — item configs, includes **The Coin** magicules restored and **the Calamity Staff** cooldown, magic slots, and chant speed.
* `trarcane/ability/skill/extra_config` — Extra Skill configs, for all Extra Skills.
* `trarcane/ability/skill/unique_config` — Unique Skill configs, for Excavation, Investigator, Holy.
