A bundle containing several spatial magic skills.

## Information

| Type      | Item |
| --------- | ---- |
| Craftable | No   |

---

## Obtaining

The Spatial Bundle can be obtained through the **Excavate** mode of the **Excavation** Unique Skill.

## Usage

Use the bundle to learn **Swipe**, **Shrink**, and **Gate**. The item is consumed on use.
