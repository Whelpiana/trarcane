A refined material created by combining magical items.

## Information

| Type      | Item |
| --------- | ---- |
| Craftable | Yes  |

---

## Obtaining

The Eclipse Ingot can be crafted using a **Tensura Smithing Bench**.

## Required Materials

| Material                          | Amount |
| --------------------------------- | ------ |
| **Pure Magisteel Ingot**          | 4      |
| **Magic Stone**                   | 4      |
| **High Quality Magic Crystal**    | 1      |
| **Pure Magisteel Gear Schematic** | 1      |


---

## Usage

The Eclipse Ingot is used as a crafting material for items requiring it.
