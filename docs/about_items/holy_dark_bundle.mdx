A bundle containing holy and dark magic skills.

## Information

| Type      | Item |
| --------- | ---- |
| Craftable | No   |

---

## Obtaining

The Holy Dark Bundle can be obtained through the **Excavate** mode of the **Excavation** Unique Skill.

## Usage

Use the bundle to learn **Solar Flare**, **Solar Rain**, **Darkness Cannon**, and **True Darkness**. The item is consumed on use.
