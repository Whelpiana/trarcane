A powerful gauntlet forged from **Eclipse Ingots**.

## Information

| Type                   | Item |
| ---------------------- | ---- |
| Craftable              | Yes  |
| Starting Attack Damage | 21   |
| Evolved Attack Damage  | 83   |

---

## Obtaining

The Gauntlet can be crafted using a **Tensura Smithing Bench**.

### Required Materials

| Material                                                                        | Amount |
| ------------------------------------------------------------------------------- | ------ |
| [**Eclipse Ingot**](/en/project/trarcane/latest/docs/about_items/eclipse_ingot) | 3      |
| **Magic Stone**                                                                 | 1      |
| **Pure Magisteel Gear Schematic**                                               | 1      |

---

## Evolution

The Gauntlet starts with **21 attack damage**.

At **750,000 EP**, the Gauntlet evolves and its attack damage increases to **83**.
