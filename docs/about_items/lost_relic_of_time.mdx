A relic whose fractured core remembers the gifts of otherworlders.

## Information

| Type          | Item         |
| ------------- | ------------ |
| Craftable     | No           |
| Availability | Creative only |

---

## Obtaining

The Lost Relic of Time is a **Creative-only** item. It is intended to give server owners a way to award it as a reward for events, quests, etc.

## Usage

Use the item to learn one random **Unique Skill** from the configured reincarnation starting skills that you do not already know. The relic is consumed after a successful use. It cannot be used if you already know all of these skills.
