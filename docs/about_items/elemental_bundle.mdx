A bundle containing several elemental magic skills.

## Information

| Type      | Item |
| --------- | ---- |
| Craftable | No   |

---

## Obtaining

The Elemental Bundle can be obtained through the **Excavate** mode of the **Excavation** Unique Skill.

## Usage

Use the bundle to learn **Blizzard**, **Megiddo**, **Hellfire**, and **Flare Circle**. The item is consumed on use.
