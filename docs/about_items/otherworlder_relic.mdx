A relic containing the soul of an Otherworlder.

## Information

| Type      | Item |
| --------- | ---- |
| Craftable | No   |

---

## Obtaining

The Otherworlder Relic can be obtained through the **Excavate** mode of the **Excavation** Unique Skill.

## Usage

Use the relic to learn one random **Otherworlder Unique Skill** that you do not know. Possible skills are **Berserker**, **Survivor**, **Spearhead**, **Bewilder**, **Healer**, **Severer**, and **Traveler**. The relic is consumed after a successful use. It cannot be used if you already know all of these skills.
