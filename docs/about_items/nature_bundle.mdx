A bundle containing several nature magic skills.

## Information

| Type      | Item |
| --------- | ---- |
| Craftable | No   |

---

## Obtaining

The Nature Bundle can be obtained through the **Excavate** mode of the **Excavation** Unique Skill.

## Usage

Use the bundle to learn **Aerial Blade**, **Electro Blast**, **Magma Surge**, and **Earth Jail**. The item is consumed on use.
