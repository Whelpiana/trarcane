Excavation allows the user to dig up increasingly rare rewards.

## Information

| Type | Unique Skill |
|------|--------------|
| Obtain Cost | 75000 MP |
| Points to Master | 1000 |

---

## Obtaining

Investigator is a Unique Skill that can be obtained through:
- Reincarnation
- Skill Reroll

---

## Usage

### [Active - Press] Analytical Appraisal

Press to activate **Analytical Appraisal**.

---

### [Active - Press] Excavate

Press the skill key to excavate a reward. Each excavation costs **100,000 magicules** and, after a successful excavation, has a **5 minute cooldown**.

The reward tier advances in order from **Common** to **Rare**, **Epic**, and **Legendary**, then returns to **Common**. After completing **the configured amount of Legendary excavations**, no further excavations are available.

Rewards are selected from the pool of the current tier. Each entry has a relative weight; entries with a higher weight have more chances to be picked.

**The rewards can be changed by the user inside "config\tensura\excavation_reward_pool.toml". The config supports other addon skills and items.**

**The maximum number of Legendary excavations is set to 3 by default. In the config mentioned above you can edit the number of Legendary Excavations a player can complete.**
